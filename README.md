## Recent Work

**[jd-witness-memory](https://github.com/Bushra31/jd-witness-memory)**

- Episodic memory for a humanoid robot.
- Turns a live stream of visible people into a timestamped SQLite diary keyed by recognised identity; the robot answers questions about earlier events from a record rather than generating them.
- Includes a replay harness that runs the whole system without hardware.

Part of **[jd_cortex](https://github.com/aima0749/jd_cortex)**, the complete robot system built with [@aima0749](https://github.com/aima0749) — vision, conversation, gesture control, and the memory layer above.
